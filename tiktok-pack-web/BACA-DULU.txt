TIKTOK PACK - CARA PAKAI
========================

Link produk (atau foto + deskripsi seller) -> paket video TikTok yang tinggal
dikerjain di Google Flow + CapCut:
- prompt FRAME buat Nano Banana: foto produk asli kamu jadi gambar storyboard
  (hero, close-up, dipegang tangan, ruang teks, scene, cover),
- prompt VIDEO buat Veo per shot (frame awal = gambar dari Nano Banana tadi),
- shot yang kamu rekam sendiri pakai HP, 5 pilihan hook, naskah voice-over,
  caption + hashtag, judul cover, musik, checklist posting.
Durasi bisa dipilih: 10, 15, 20, 30, 45, atau 60 detik.
Semua jalan di PC kamu sendiri. Yang dikirim ke internet cuma ke z.ai (dan ke
halaman produk kalau kamu pakai fitur ambil info dari link).

PERTAMA KALI
1. Klik kanan file zip -> Properties -> centang "Unblock" -> OK.
2. Klik kanan zip -> Extract All. Jangan jalanin dari dalam zip.
3. Buka folder hasil ekstrak, klik dua kali "Mulai" (file .bat, ikon roda gigi).
   - Kalau muncul "Windows protected your PC": klik More info -> Run anyway.
   - Pertama kali download sekitar 30 MB (Python + library), 1-3 menit.
   - Browser kebuka sendiri. Kalau gak, buka http://127.0.0.1:8765
4. Pertama kali, jendela Pengaturan z.ai muncul sendiri (nanti bisa dibuka lagi
   lewat ikon roda gigi di kanan atas). Tempel API key, klik "Simpan & cek key".
   API key ambil di z.ai: login -> menu API Keys -> bikin key baru.
   Saldo z.ai (pay-as-you-go) harus ada isinya.

PEMAKAIAN
1. Tempel link produk (tombol Bagikan di TikTok Shop / Tokopedia -> Salin link),
   klik "Ambil info". Nama, harga, diskon, deskripsi, dan foto produk keisi
   sendiri. Harga & diskon cuma info buat kamu, gak dimasukin ke naskah video.
   Link gak kebaca (diblok/minta login)? Pakai tombol bookmark (lihat bawah),
   atau tempel deskripsi & foto manual.
2. Foto produk (opsional, maks 3): tarik ke kotak foto, Ctrl+V, atau klik.
   Biar AI bisa baca label, tutup & warna. JPG/PNG/WebP; HEIC gak bisa.
3. Cek deskripsi produk (boleh diedit).
4. Pilih durasi dan gaya video. "Otomatis" ganti-ganti template tiap video,
   biar akun kamu gak dianggap posting video yang mirip-mirip.
   - Centang "Aku pegang produknya" kalau produknya ada di tangan kamu: ada shot
     rekam nyata (ambil, semprot, ukuran, kemasan) dan gaya Unboxing kebuka.
   - Centang "Aku udah pernah pakai" cuma kalau memang udah.
5. Klik "Bikin paket" (atau Ctrl+Enter), tunggu sekitar 20-60 detik.
6. Pilih hook yang paling kamu suka. Shot 1, naskah VO, dan brief ikut ganti.
7. "Download brief (.txt)": semua prompt & naskah dalam satu file (bisa dibuka
   di HP).

TOMBOL BOOKMARK (kalau link gak bisa diambil otomatis)
1. Munculin bookmark bar: Ctrl+Shift+B.
2. Di aplikasi, buka "Link gak kebaca? Pakai tombol bookmark", tarik tombol
   "Kirim ke TikTok Pack" ke bookmark bar (sekali aja).
3. Buka link produk di browser sampai halamannya kebuka penuh, klik bookmark
   itu. Tab TikTok Pack kebuka, klik "Ambil info".

BIKIN DI GOOGLE FLOW
Langkah 1 - Frame (Nano Banana), mulai dari Frame Hero:
- Flow -> Image -> 9:16 -> upload foto produk asli (frame lain: foto produk asli
  + Frame Hero) -> tempel prompt frame -> Generate -> pilih yang produknya paling
  persis aslinya (label, tutup, warna, ukuran) -> download.
Langkah 2 - Video (Veo) per shot AI:
- Flow -> Video -> Frames to Video -> start frame = frame yang disebut di shot
  itu -> tempel prompt video -> Generate. Penutup loop: start DAN end frame sama.
- Cek tiap klip: label, tutup, warna, ukuran harus sama, jari tangan harus 5.
  Ada yang berubah -> generate ulang, jangan dipakai.
- Kredit Flow: Veo 3.1 Fast 20 kredit per klip, Lite 10 (buat coba-coba).
Langkah 3 - Shot "REKAM SENDIRI" pakai HP, lalu gabung semua di CapCut sesuai
urutan storyboard, rekam voice-over pakai suara kamu sendiri, export 1080p.

SEBELUM POSTING (lengkapnya ada di checklist aplikasi)
- Nyalain label konten AI dan pengungkapan konten komersial.
- Pasang Frame Cover (+ judul cover) sebagai cover. Link produk lewat
  keranjang kuning.
- Musik dari Commercial Music Library TikTok.
- Cek nomor BPOM di cekbpom.pom.go.id.

BIAYA z.ai
- Cuma teks: sekitar Rp100-300 per paket (tergantung model & durasi), ambil info
  dari link juga segitu. Gak ada lagi biaya gambar di z.ai.
- Semua hasil tersimpan di folder data\hasil\.

PENTING
- Jangan tutup jendela hitam selama dipakai. Tutup jendela = aplikasi berhenti.
- Kalau judul jendela hitam ada tulisan "Select", tekan Esc.

KALAU ADA MASALAH
- Gagal memasang uv: buka PowerShell, jalankan
  powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  atau: winget install astral-sh.uv
  Lalu buka Mulai lagi.
- "Aplikasi gak nyambung" di browser: jendela hitamnya ketutup. Buka Mulai lagi.
- Error lain: foto layar jendela hitam dan kirim ke Claude.
